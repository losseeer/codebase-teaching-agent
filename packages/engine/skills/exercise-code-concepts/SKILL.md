# 出机制题（练习侧）

为当前仓库出代码题时使用；讲题走 `teach-code-concepts`；判分只由沙箱测试结果决定。
## 准入条件

三条同时满足才出题；任一不满足，返回拒绝并更换考点。

1. 目标函数连同替身可独立编译运行，不依赖容器、网络、真实数据库、真实时钟与线程调度。
2. 存在一个具体改动，能使测试从失败变为通过（或相反）；给不出该改动，按背诵题处理。
3. 题面所需信息在摘录内可读全，学习者无需查看仓库其他部分。
## 主题与考点

主题按代码证据判定（标识符、结构、配置项），不按目录名推断；领域与语言两层都取。

| 主题 | 附属文件 | 常见缺陷 |
| --- | --- | --- |
| 并发与 IO | `os.md` | 漏释放、复合操作未保护、上下文未清理、队列溢出策略错误 |
| 传输与序列化 | `cn.md` | 超时或重试缺失、重复投递未拦截、字段契约不一致 |
| 数据结构与算法 | `ds.md` | 边界条件、比较器不自洽、可变对象作键、淘汰顺序错误 |
| 后端工程结构 | `backend.md` | 事务边界错误、缓存与写库顺序错误、幂等判据缺失 |
| Java | `java.md` | `equals`/`hashCode` 不成对、包装类型 `==`、`subList` 视图、空集合返回 null |
| Go | `go.md` | slice 共享底层数组、nil map 写入、接口 nil 判空失效、错误被覆盖 |
| Python | `python.md` | 可变默认参数、闭包晚绑定、`is` 与 `==`、浅拷贝 |
| TypeScript / JavaScript | `typescript.md` | `==` 隐式转换、浮点累加、`NaN` 自比较、`sort` 默认字典序 |
## 出题策略

`unit`：题目锚定给定代码单元，参考解逐字取自该段源码。`reference`：源码仅作参考，素材自行检索；无摘录时使用检索与读文件工具获取。
## 产出要求

- 题型：`patch_edit` 的下发件含一处行为级缺陷，参考解为仓库原实现；`author_function` 给出签名与示例，不复述算法步骤；定位题的候选项取自索引；影响分析的标准答案由依赖图计算。
- 测试：只断言返回值与状态变化；依赖时钟、随机数、线程池、连接池时摘出可判定的一层；每条断言可单独失败，至少一条针对该缺陷；按语言输出计数结论行，不以退出码表达成败。
- 题面：按 `## 问题描述` / `## 示例` / `## 注意事项` 三节写，缺一即不合格；示例只给调用与期望返回，不复刻断言；不指出缺陷所在行或待改条件；题面内代码事实必须能在摘录中找到；标题具体到真实符号。
- 自证：沙箱运行两次，参考解全部通过、下发件至少一条失败；任一不成立即拒绝，禁止放宽测试或删除断言。禁止项：编造仓库中不存在的代码形状；把未证实的运行时行为写成题面事实；题面给出待考结论；重复提交同一份题面。
